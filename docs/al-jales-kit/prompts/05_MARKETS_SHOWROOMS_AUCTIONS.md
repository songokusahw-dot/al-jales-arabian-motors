# المرحلة 05 — الأسواق والمعارض الكورية والمزادات

نفّذ صفحات الأسواق والمعارض والمزادات باستخدام مكونات مشتركة وبيانات config موحدة.

## 1. صفحات السوق

- `/cars/korea`: سيارات كوريا ومعلومات الاستيراد، كل الأسعار في الواجهة SAR.
- `/cars/saudi`: سيارات معرض السعودية.
- `/cars/yemen`: سيارات معرض اليمن.

كل الصفحات تستخدم VehicleListingPage نفسها مع market config مختلف: عنوان، وصف، شارة السوق، مقدمة تحريرية، وفلتر السوق الثابت. لا تكرر Search/Filter/Card implementation.

## 2. سياراتنا / اختيار المعرض

`/our-showrooms` تعرض ثلاثة Market Portals: كوريا، السعودية، اليمن. الضغط يفتح صفحة السيارات الخاصة بالسوق. اجعل مكان المعرض وحالة المخزون واضحين دون اختلاق عنوان أو عدد سيارات حقيقي.

## 3. المعارض الكورية

`/korea/showrooms` صفحة مستقلة لمصادر/معارض كوريا. اعرض اسم المصدر وشعاره وموقعه وسياراته فقط إذا كانت بياناته أصلية معتمدة. إذا لم تتوفر أسماء شركاء فعلية، استخدم قسم «مصادر السيارات الكورية» مع رسالة أن بيانات الشركاء ستضاف لاحقاً؛ لا تخترع شركات أو شعارات.

## 4. المزادات الكورية

`/korea/auctions` صفحة مستقلة تعرض سجلات المزادات التجريبية/الموثقة. قد تتضمن رقم المرجع، المصدر، بيانات السيارة، الصور، السنة، الممشى، الحالة والسعر عند وجودها.

- لا تنشئ real-time bidding أو countdown أو أعلى مزايد أو sold price من خيالك.
- أي مزاد تجريبي موسوم Demo.
- الفلاتر قابلة للتشغيل على البيانات الموجودة، والبطاقة تفتح صفحة معلومات واضحة.
- عند عدم وجود بيانات مزادات حقيقية، اعرض Empty state مناسباً بدلاً من قائمة مزادات مختلقة.

## 5. رحلة الاستيراد

استخدم خمس مراحل أو ما يثبت ملاءمته في المرجع: اختيار المصدر، الفحص، التصدير، الشحن، التخليص والتسليم. استخدم رسم SVG توضيحياً، ولا تستخدم خرائط أو أزمنة أو موانئ/مسافات حقيقية دون بيانات موثقة.

## معيار القبول

كل سوق يفلتر البيانات الصحيحة؛ قوالب السوق مشتركة؛ `/our-showrooms` تعمل؛ صفحة المعارض الكورية منفصلة عن صفحة المزادات؛ لا أسماء شركاء/أسعار/مزايدات/عناوين مزيفة.
