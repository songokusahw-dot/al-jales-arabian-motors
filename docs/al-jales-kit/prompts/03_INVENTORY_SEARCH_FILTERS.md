# المرحلة 03 — كتالوج السيارات والبحث والفلاتر

نفّذ `/cars`, `/search`, `/cars/korea`, `/cars/saudi`, `/cars/yemen` باستخدام منطق مشترك. لا تنسخ صفحة مستقلة لكل سوق.

## 1. واجهة القائمة

- عنوان ووصف يتغيران حسب السوق.
- شريط بحث يطابق العلامة والموديل واسم السيارة العربي/الإنجليزي والرقم المرجعي.
- عدد النتائج، الفلاتر النشطة كـ chips، زر مسح الكل.
- شبكة بطاقات متجاوبة وpagination صحيحة.
- فلاتر desktop جانبية أو أفقية؛ على الهاتف تفتح Drawer/Sheet واضحاً.

## 2. الفلاتر المطلوبة

- السوق KR/SA/YE.
- العلامة، والموديل الذي تتغير خياراته حسب العلامة.
- سنة الصنع من/إلى.
- السعر من/إلى SAR.
- المسافة بالكيلومتر من/إلى.
- نوع الوقود: بنزين، ديزل، هايبرد، كهرباء، وغاز عند وجود بيانات.
- ناقل الحركة: أوتوماتيك أو عادي.
- نوع الهيكل، اللون، حالة السيارة، حالة الفحص عند وجود بيانات موثقة.

## 3. البحث العربي والـURL

- طبّع نص البحث: Unicode normalization، إزالة التشكيل والتطويل، توحيد المسافات، وcase-insensitive للإنجليزية. تجنب تحويلات عربية عدوانية تغيّر معنى الحروف.
- دعم aliases عربية/لاتينية للعلامة عند وجودها في brand data.
- أبقِ q وbrand وmarket وyearFrom/yearTo وpriceMin/priceMax وfuel وtransmission وsort وpage داخل URL search params.
- تحديث الفلاتر يعيد pagination إلى الصفحة الأولى. Back/Forward يعيد الحالة. شارك الرابط فيفتح بنفس النتائج.
- إذا كان market محدداً بالمسار، لا تسمح لفلتر URL أن يعرض سوقاً آخر إلا إذا كان ذلك مقصوداً وموضحاً.

## 4. الترتيب والنتائج

- الأحدث: `createdAt desc`.
- السعر الأقل/الأعلى: `finalPriceSAR` أو `salePriceSAR` مع تجاهل null بشكل صريح.
- الأقل ممشى: mileage asc.
- السنة ليست بديلاً عن createdAt عند اختيار «الأحدث».
- نفّذ pagination بعد تطبيق الفلاتر والترتيب، واجعل totalPages هو عدد الصفحات وليس عدد السيارات.
- empty state عربي مفيد مع زر «مسح الفلاتر» واقتراح العودة إلى كل السيارات.
- loading/error states حقيقية بحسب طريقة البيانات؛ لا تصنع loaders وهمية للبيانات المحلية الفورية.

## 5. بطاقات السيارة

وحّد VehicleCard مع بطاقة الرئيسية. أظهر السنة/الوقود/القير/الممشى والسعر بوضوح. لا تستخدم حالة أو تقريراً غير موجود. دعم available/reserved/sold مع CTA مناسب لكل حالة.

## 6. معيار القبول

- البحث يطابق العربية والإنجليزية وأرقام المرجع.
- الفلاتر مترابطة، وتعمل على كل الأسواق، والموديل يتبع العلامة.
- الترتيب حسب التاريخ/السعر/الممشى صحيح.
- الفلاتر قابلة للمشاركة عبر URL، وBack/Forward صحيح.
- pagination لا تحسب عدد السيارات بوصفه عدد الصفحات.
- لا نتائج؟ يظهر Empty state واضح.
- اختبر 1440 و768 و390 و360px، وRTL بالكامل.
