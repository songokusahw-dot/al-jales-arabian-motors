# المرحلة 06 — النماذج والمحتوى والتواصل

نفّذ الصفحات التالية بواجهة عربية متناسقة، مع التحقق من المدخلات وحالات الإرسال التجريبية.

## 1. طلب سيارة — `/request-car`

نموذج متعدد الخطوات مع progress stepper:
1. السوق المطلوب (KR/SA/YE أو مفتوح).
2. العلامة والموديل أو «لا يوجد موديل محدد».
3. سنة الصنع والنطاق السعري SAR.
4. الوقود والقير واللون والمواصفات المطلوبة.
5. ملاحظات إضافية.
6. بيانات العميل: الاسم، الهاتف، المدينة/الدولة، البريد اختياري.
7. مراجعة البيانات ثم إرسال محلي تجريبي.

تحقق من الحقول، صيغة الهاتف والبريد إن أدخلا، وضوح الأخطاء بالعربية، حفظ البيانات خلال تنقل الخطوات، وإمكانية الرجوع/التعديل. بعد الإرسال اعرض بوضوح: «هذا نموذج تجريبي — لم يتم إرسال الطلب إلى الشركة».

## 2. تقييم العملاء — `/reviews`

- اعرض مراجعات حقيقية فقط إذا زودت الشركة بها.
- إذا لم توجد مراجعات، اعرض Empty state يدعو المستخدم لإضافة تقييم.
- نموذج التقييم: الاسم، النجوم 1–5، نص التقييم، السيارة اختيارية.
- تخزين محلي مؤقت فقط، مع توضيح أنه غير منشور وغير مرسل للشركة.
- لا تستخدم أسماء عملاء أو نجوم وهمية دون وصفها Demo.

## 3. الأسئلة الشائعة — `/faq` وطرح سؤال — `/ask-question`

- FAQ في Accordion قابل للكيبورد.
- صفحة مستقلة لطرح سؤال: الاسم، وسيلة التواصل (اختياري/حسب الحاجة)، تصنيف السؤال، النص.
- بعد الإرسال: «تم حفظ السؤال محلياً كتجربة فقط؛ لم يصل إلى الشركة».

## 4. من نحن — `/about`

قصة الشركة، الرؤية، الخدمات، الأسواق الثلاثة ورحلة الاستيراد. استخدم نصاً تعريفياً قابلاً للتعديل، ولا تختلق سنوات خبرة أو أعداد سيارات أو شهادات أو شراكات.

## 5. التواصل والمواقع — `/contact` و`/locations`

- أرقام الهاتف، WhatsApp، البريد، عناوين الفروع، ساعات العمل والروابط الاجتماعية من `siteConfig` فقط.
- القيمة الفارغة لا تُعرض كرابط. إذا لا يوجد رقم WhatsApp، استبدل الزر بنموذج التواصل.
- لا تُنشئ خريطة pin دون إحداثيات معتمدة. اعرض بطاقة الدولة/الفرع ومعلومة أن البيانات ستضاف لاحقاً.
- مكونات أيقونات التواصل Inline SVG داخلية مع `aria-label`، ولا تعرض منصة ليس لها URL حقيقي.
- نموذج التواصل محلي تجريبي فقط ما لم يكن التكامل الفعلي معتمداً.

## 6. التذييل

Footer متكامل، روابط الصفحات الرئيسية، الأسواق، خدمة العملاء، الروابط الاجتماعية المؤكدة، والصفحات القانونية. لا تكرر روابط مكسورة.

## معيار القبول

النماذج تتحقق من الحقول وتعرض رسائل عربية؛ لا تدّعي التسليم الحقيقي؛ التقييمات الحقيقية فقط أو Empty state؛ بيانات التواصل مركزية ولا تحتوي أرقاماً وهمية؛ جميع روابط Footer تعمل.
