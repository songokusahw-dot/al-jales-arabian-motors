# نظام الألوان HSL والتباين

## مصدر القرار

قيم ARCO أدناه مأخوذة من جرد مرجع ARCO المحفوظ للمشروع، وتُستخدم كنقطة انطلاق إذا كان هذا المرجع ضمن المجموعة المعتمدة فعلياً في المشروع المفتوح. إذا كانت هناك ملفات أو Screenshots أحدث ومختارة من المستخدم، فيجب اشتقاق الألوان النهائية منها بدلاً من فرض هذه القيم.

## تحويل القيم الأساسية إلى HSL

| Token | Hex مرجعي | HSL (تقريب لأقرب درجة/نسبة) | الاستخدام |
|---|---|---|---|
| Canvas Light | `#E9EAEC` | `220 7% 92%` | خلفية الصفحة الفاتحة. |
| Panel Light | `#D4D6D8` | `210 5% 84%` | Surface ثانوية/منطقة صورة. |
| Surface | `#FFFFFF` | `0 0% 100%` | بطاقات ومناطق مرتفعة. |
| Ink | `#121316` | `225 10% 8%` | العناوين والنص الداكن. |
| Muted Ink | `#54585D` | `213 5% 35%` | نص ثانوي مع تباين كافٍ على اللوحات الفاتحة. |
| Reference Red | `#CC2C24` | `3 70% 47%` | Accent للأزرار/العناصر البارزة. |
| Accessible Red Text | `#C0261F` | `3 72% 44%` | نص accent صغير على خلفية Light. |
| Dark Surface | `#24262B` | `223 9% 15%` | أسطح في Dark mode. |
| Dark Surface Raised | `#34373D` | `220 8% 22%` | سطح مرتفع/بطاقة داكنة. |
| Dark Text | `#F5F6F7` | `210 11% 96%` | نص رئيسي في Dark. |
| Dark Muted Text | `#AEB4BD` | `216 10% 71%` | نص ثانوي في Dark. |
| Dark Accent Text | `#F06D65` | `3 82% 67%` | accent text على الأسطح الداكنة. |

## Semantic tokens المقترحة

```css
:root,
[data-theme="light"] {
  --background: 220 7% 92%;
  --foreground: 225 10% 8%;
  --surface: 0 0% 100%;
  --surface-muted: 210 5% 84%;
  --text-muted: 213 5% 35%;
  --border: 220 5% 78%;
  --primary: 3 70% 47%;
  --primary-foreground: 0 0% 100%;
  --primary-text: 3 72% 44%;
  --focus: 212 100% 42%;
}

[data-theme="dark"] {
  --background: 225 10% 8%;
  --foreground: 210 11% 96%;
  --surface: 223 9% 15%;
  --surface-muted: 220 8% 22%;
  --text-muted: 216 10% 71%;
  --border: 220 8% 28%;
  --primary: 3 70% 47%;
  --primary-foreground: 0 0% 100%;
  --primary-text: 3 82% 67%;
  --focus: 210 100% 72%;
}
```

اجعل CSS tokens semantic، ولا تكتب hex مباشرة في مكونات الصفحات. `--primary` هنا خلفية زر مع نص أبيض؛ `--primary-text` مخصص للنصوص الصغيرة حتى يمر التباين.

## تحقق التباين WCAG

قيم contrast ratio المحسوبة وفق relative luminance، ومقربة إلى منزلتين:

| Foreground | Background | Ratio | النتيجة |
|---|---|---:|---|
| `#121316` | `#E9EAEC` | 15.43:1 | Pass AAA للنص العادي. |
| `#54585D` | `#D4D6D8` | 4.92:1 | Pass AA للنص العادي. |
| `#C0261F` | `#E9EAEC` | 4.93:1 | Pass AA للنص العادي. |
| `#FFFFFF` | `#CC2C24` | 5.31:1 | Pass AA للنص العادي. |
| `#F5F6F7` | `#121316` | 18.58:1 | Pass AAA للنص العادي. |
| `#AEB4BD` | `#24262B` | 7.25:1 | Pass AAA للنص العادي. |
| `#F06D65` | `#24262B` | 5.10:1 | Pass AA للنص العادي. |

**مهم:** اللون الأحمر المرجعي `#CC2C24` على الخلفية `#E9EAEC` يحقق تقريباً 4.41:1، لذلك لا تستخدمه كنص صغير فوق هذه الخلفية. استخدم `Accessible Red Text` أو النص الداكن. استخدم الأبيض فوق زر أحمر؛ لا تضع أبيض فوق canvas فاتح.

## قواعد إضافية

- التحقق من جميع حالات hover/disabled/focus والـbadges، وليس الوضع الافتراضي فقط.
- لا تستخدم opacity لتخفيض النص حتى يهبط التباين.
- اللون لا يكون الوسيلة الوحيدة لشرح available/reserved/sold أو حالة الفحص؛ أضف نصاً/أيقونة.
- إذا اشتُقت palette أخرى من المرجع المعتمد، أعد قياس التباين بدلاً من نسخ هذه النسب.
