AL-JALES AUTOMOTIVE — تعليمات المشروع الدائمة لـ Lovable

الدور والهدف
- ابنِ تجربة رقمية عربية فاخرة لشركة الجالس للسيارات، لا قالب إعلانات مبوبة.
- الأسواق: كوريا KR (مصادر/استيراد)، السعودية SA (معرض محلي)، اليمن YE (معرض محلي).
- النصوص المعروضة بالعربية وRTL. أبقِ أسماء الموديلات والأكواد والقياسات LTR مع bidi isolation. استخدم CSS logical properties.

قاعدة أولى إلزامية
- قبل أي تعديل، افحص الملفات الفعلية ذات الصلة، package.json وlockfile، الراوتر، الستايلات، المكونات، الأصول، Git status وdiff. لا تفترض وجود ملفات/مكتبات لم ترها.
- حافظ على إطار العمل والبنية والوظائف الحالية. لا تعِد scaffold ولا تحذف أو تستبدل عملاً سليماً. لا تثبّت حزمة قبل فحص الموجود.
- عند SSR (بما فيه TanStack Start الحالي في المشاريع الجديدة)، لا تستخدم window/document عند module scope. هيّئ GSAP وLenis وEmbla في client lifecycle مناسب وبعد mount.

المرجع البصري
- Light هو الثيم الافتراضي؛ وفّر Dark theme فعلياً مع Theme toggle محفوظ. كل المكونات تستجيب لمتغيرات الثيم.
- اعتمد المراجع الأحدث الموجودة في المشروع/المرفقات. إذا وُجد مرجع أحدث من ملفات AL-JALES السابقة، فهو المرجع. إذا كان مرجع ARCO هو المعتمد، استخدم قيمه المحايدة كنقطة بدء: أرضية رمادية فاتحة، أسطح بيضاء، حبر فحمي ولمسة حمراء محسوبة التباين.
- لا تستدعِ اتجاه Obsidian/Champagne السابق، ولا تستخدم Gold/Bronze/Beige كهوية. لا تفرض لوناً جديداً قبل فحص المراجع. اجعل التباين للنص العادي 4.5:1 على الأقل.
- الواجهة Premium Editorial: صور كبيرة، فراغات مدروسة، بطاقات مركبة غير جامدة، وضوح السعر والمواصفات، حركات قليلة لكنها دقيقة.

التقنيات والحركة
- حافظ على الراوتر والإطار الحالي. المشاريع الجديدة على Lovable قد تكون TanStack Start/Router؛ القديمة قد تكون React/Vite.
- Scroll scenes: GSAP + ScrollTrigger + @gsap/react. Micro-interactions: motion/react إذا لم توجد Framer Motion مسبقاً. لا تكرر مكتبات الحركة.
- Lenis اختياري، طبقة واحدة فقط، مع مزامنة ScrollTrigger عند الحاجة. لا wheel/touch hijacking ولا preventDefault لتعطيل scroll.
- شريط الماركات: Embla v8 stable مع Auto Scroll عند الحاجة؛ RTL حقيقي، drag/swipe، pause on hover/focus، وتحقق بصري من اتجاه اليمين إلى اليسار.
- لا تحرك transform للعنصر نفسه بواسطة GSAP وMotion معاً. نظّف contexts/listeners/observers. ادعم prefers-reduced-motion وخفف pinning على الهاتف.

الصفحات والمسارات
- / — الرئيسية.
- /cars — كل السيارات.
- /cars/korea و/cars/saudi و/cars/yemen — نفس قالب القائمة مع market مختلف.
- /car/:slug — تفاصيل سيارة.
- /search — بحث شامل.
- /brands/:brandSlug — صفحة ماركة إذا كانت مفيدة للبيانات.
- /korea/showrooms و/korea/auctions — صفحات مستقلة.
- /our-showrooms و/request-car و/about و/reviews و/faq و/ask-question و/contact و/locations.
- /privacy و/terms و/cookies، مع صفحة 404 حقيقية.
- لا تكرر منطق صفحات الأسواق؛ استخدم shared listing component وroute config.

البيانات والمال
- واجهة البيانات Typed TypeScript ومنفصلة عن المكونات. 18 مركبة تجريبية تقريباً (6 لكل سوق) عند الحاجة، وكل رقم/تقييم/توفّر تجريبي موسوم Demo.
- أكواد مرجعية فريدة: KR-01001، SA-01001، YE-01001 مع تسلسل مستقل لكل سوق.
- عملة العرض الافتراضية SAR لكل الأسواق. سعر KRW→SAR التجريبي 0.00275 فقط للعرض التعليمي، وليس سعر صرف حياً. اعرض عناصر تفصيل السعر بعملة البيع SAR؛ لا تعرض تكلفة أو رسماً غير موثق.
- أحدث السيارات ترتب حسب createdAt تنازلياً، لا حسب السنة ولا ترتيب عشوائي.
- حالات السيارة: available / reserved / sold. لا تفعّل الحجز أو البيع عند sold.
- البحث والفلاتر قابلة للمشاركة عبر URL search params وتدعم العربية والإنجليزية. اعرض empty state عند عدم وجود نتائج.

صور وشعارات واتصال
- لا تولّد صور سيارات. استخدم صوراً أصلية/مرخصة ومطابقة للمركبة؛ وإلا Placeholder واضح لا يدّعي أنه السيارة.
- يمكن استخدام صور أجواء مجردة لا تحتوي على سيارات أو علامات تجارية حقيقية. اجعل الأصول مركزية وقابلة للاستبدال مع alt text ومصدر/ترخيص.
- استخدم شعار العلامة الرسمي فقط عند توفر ملف موثوق؛ وإلا اسم نصي. أيقونات التواصل Inline SVG واظهر الحسابات التي لها URL فعلي فقط.
- phone/WhatsApp/email/addresses/coordinates null حتى يزوّد بها المستخدم. لا أرقام أو خرائط أو روابط وهمية. عند غياب WhatsApp استخدم نموذج التواصل.

نطاق النسخة
- Frontend prototype فقط، ما لم يطلب المستخدم لاحقاً صراحةً نطاقاً آخر. لا تضف DB أو Supabase أو APIs أو auth أو payments أو scraping.
- النماذج والتقييمات والأسئلة تحفظ محلياً كعرض تجريبي فقط. لا تقل «تم الإرسال إلى الشركة»؛ اذكر «لم يتم إرسال البيانات».
- لا تضف analytics أو pixels أو session replay أو tracking cookies دون موافقة صريحة.
- صفحات الخصوصية والشروط/الكوكيز مسودات تحتاج مراجعة الشركة/القانونية. لا تدّعِ أنها معتمدة.

الجودة والتسليم
- اختبر 1440px و1024px و768px و390px و360px، مع RTL وLight/Dark وreduced motion.
- اختبر كل رابط، فلتر، ترتيب، pagination، gallery/lightbox، form validation، status states و404.
- افحص console/network والأخطاء، وشغّل scripts المتاحة فعلاً (lint/typecheck/test/build). أصلح الأعطال ولا تكتفِ بسردها.
- في نهاية كل مرحلة اذكر changed files/routes، dependencies added/avoided، الاختبارات ونتائجها، وما بقي Placeholder. لا تنتقل تلقائياً إلى مرحلة أخرى دون اكتمال قبول المرحلة الحالية.
