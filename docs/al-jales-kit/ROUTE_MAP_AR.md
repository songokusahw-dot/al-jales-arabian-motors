# خريطة الصفحات والمسارات — AL-JALES

| الصفحة | المسار Canonical | ملاحظات التنفيذ |
|---|---|---|
| الرئيسية | `/` | Hero، العلامات، أحدث السيارات، الأسواق، رحلة الاستيراد، السعر، CTA. |
| كل السيارات | `/cars` | القائمة العامة؛ shared listing component. |
| سيارات كوريا | `/cars/korea` | نفس قالب القائمة مع market=KR. |
| سيارات السعودية | `/cars/saudi` | نفس قالب القائمة مع market=SA. |
| سيارات اليمن | `/cars/yemen` | نفس قالب القائمة مع market=YE. |
| تفاصيل السيارة | `/car/:slug` | مسار منفصل لتفادي التعارض مع `/cars/:market`. |
| البحث | `/search` | يستخدم منطق البحث والفلاتر نفسه مع query. |
| صفحة علامة | `/brands/:brandSlug` | اختياري ومبني فوق نفس inventory query. |
| المعارض الكورية | `/korea/showrooms` | دليل مصادر/معارض كوريا عند توافر بيانات معتمدة. |
| مزادات كوريا | `/korea/auctions` | صفحة مستقلة؛ لا مزايدات مباشرة وهمية. |
| سياراتنا / اختيار المعرض | `/our-showrooms` | ثلاث بطاقات: KR/SA/YE. |
| اطلب سيارة | `/request-car` | Multi-step form. |
| من نحن | `/about` | محتوى الشركة ورحلة الاستيراد. |
| تقييمات العملاء | `/reviews` | مراجعات حقيقية فقط أو Empty state. |
| الأسئلة الشائعة | `/faq` | Accordion. |
| اطرح سؤالاً | `/ask-question` | نموذج محلي تجريبي. |
| تواصل معنا | `/contact` | بيانات من siteConfig فقط. |
| الفروع والمواقع | `/locations` | لا خرائط دقيقة دون إحداثيات موثوقة. |
| الخصوصية | `/privacy` | مسودة للمراجعة القانونية. |
| الشروط والأحكام | `/terms` | مسودة للمراجعة القانونية. |
| ملفات الارتباط | `/cookies` | مسودة؛ لا تُنشئ cookies غير لازمة. |
| غير موجود | `*` أو route catch-all | 404 مخصصة.

## قواعد منع التكرار

1. صفحات `/cars/korea`, `/cars/saudi`, `/cars/yemen` تعتمد `VehicleListingPage` واحدة مع إعداد `market`؛ لا تنشئ 3 صفحات مكررة بالكود.
2. `/search` لا يعيد بناء الفلاتر من الصفر؛ يستخدم نفس service/query logic.
3. `/brands/:brandSlug` يمرر brand filter إلى نفس محرك الاستعلام.
4. صفحة التفاصيل `/car/:slug` مستقلة عن مسارات الأسواق.
5. أسماء المسارات ثابتة lower-case وبـkebab-case عند الحاجة؛ لا تخلط `/vehicles`, `/cars`, `/auto` لنفس المورد.
6. إذا كان إطار المشروع يستخدم file-based routing، فحوّل المسارات أعلاه إلى صياغة ملفات الإطار دون تغيير URLs العامة.
